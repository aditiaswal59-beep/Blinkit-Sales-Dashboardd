
# 🛒 Blinkit Sales Dashboard (Power BI)

## 📊 Project Overview
This project presents an interactive sales dashboard built using Power BI to analyze Blinkit grocery sales data. The dashboard provides insights into sales performance, item distribution, outlet characteristics, and customer ratings.

---

## ❓ Problem Statement
The goal of this project is to analyze retail sales data and answer key business questions such as:
- Which outlet types and sizes generate the highest sales?
- How do item categories contribute to total revenue?
- What is the average sales and rating performance?
- How does outlet establishment year impact sales?

---

## 🛠️ Tools & Technologies Used
- Power BI (Data Visualization)
- Microsoft Excel (Data Source & Cleaning)

---

## 📈 Key Insights
- 💰 **Total Sales** reached $230K+, indicating strong overall performance.
- 🏬 **Supermarket Type1 outlets** contributed the highest sales.
- 📦 **Household and Snack Food items** are top-performing categories.
- 📍 **Tier 2 locations** generated the highest revenue among locations.
- ⭐ Average rating is **3.9**, showing moderate customer satisfaction.
- 📅 Sales peaked around **2017–2018**, indicating optimal outlet establishment period.

---

## 🎯 Features of Dashboard
- Interactive **slicers (filters)** for:
  - Outlet Location
  - Outlet Size
  - Item Type
- KPI Cards:
  - Total Sales
  - Average Sales
  - Number of Items
  - Average Rating
- Visualizations:
  - Sales by Item Type
  - Fat Content Distribution
  - Outlet Size Analysis
  - Sales Trend by Establishment Year
- Custom UI with **navigation panel & reset button**
